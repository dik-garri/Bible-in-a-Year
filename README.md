# Библия за год

Telegram-бот для ежедневной рассылки текстов Библии с кнопками для чтения в двух переводах (Синодальный и НРП). Также включает локальный просмотрщик текстов.

## Возможности

- Автоматическая отправка текстов для чтения в Telegram-канал/группу
- 2 кнопки под сообщением (Синодальный / НРП) со ссылками на просмотрщик
- HTML-просмотрщик текстов на GitHub Pages
- Sticky-заголовок главы с прогресс-баром при скролле
- Выделение и копирование стихов (одного или нескольких)
- Управление размером шрифта (A−/A+)
- Тёмная / светлая тема
- JSON-файлы обоих переводов

## Установка бота

### 1. Создай Telegram бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Сохрани токен

### 2. Получи chat_id канала

Добавь [@userinfobot](https://t.me/userinfobot) в канал — он напишет chat_id.

### 3. Подготовь Google Sheets

Создай таблицу с двумя колонками:

| Дата | Чтение |
|------|--------|
| 01-01-2025 | Бытие 1-3; Матфея 1 |
| 02-01-2025 | Бытие 4-6; Матфея 2 |

Формат даты: `dd-MM-yyyy`

### 4. Настрой Apps Script

1. В таблице: **Расширения → Apps Script**
2. Скопируй код из `src/Code.gs`
3. Замени константы:
   ```javascript
   const TELEGRAM_TOKEN = 'твой_токен';
   const CHAT_ID = '-100xxxxxxxxxx';
   ```
4. Сохрани (Ctrl+S)

### 5. Настрой триггер

1. В Apps Script: **Триггеры → Добавить триггер**
2. Функция: `sendReadingFromSheet`
3. Тип: **По времени → Ежедневно**
4. Выбери время отправки

## Формат сообщений

Бот отправляет сообщение с 2 кнопками:

```
📖 Тексты на сегодня:
Бытие 1-3
Матфея 1

[Синодальный]  [НРП]
```

Кнопки ведут на GitHub Pages viewer с полным текстом чтения.

## Просмотрщик

**GitHub Pages:** https://dik-garri.github.io/Bible-in-a-Year/viewer/

**Локально:**
```bash
python3 -m http.server 8000
# Открой: http://localhost:8000/viewer/
```

**URL-параметры:**
```
/viewer/?q=Бытие 1-3
/viewer/?q=Матфея 5:1-10&t=nrt
```
- `q` — текст для загрузки
- `t` — перевод (`synod` или `nrt`)

**Визуальный выбор:**
1. Выбери завет (Ветхий / Новый)
2. Выбери книгу из сетки
3. Выбери главу — текст отобразится автоматически

**При чтении:**
- Заголовок главы закрепляется вверху: `Бытие — Глава 1:14` (стих обновляется при скролле)
- Тонкий прогресс-бар показывает прогресс чтения главы
- Нажми на стих — он выделяется; можно выделить несколько
- Внизу появляется панель «Копировать» для выбранных стихов
- Формат копирования: `Бытие 1:2,21-22 (Синодальный)` + текст стихов (книги разделяются блоками)
- Кнопка «?» рядом с полем ввода — примеры форматов в попапе
- Поиск по всей Библии (🔍 или Ctrl+F): находит стихи по словам в любом порядке
  - Сортировка: точная фраза → все слова → частичные совпадения
  - Клик по результату открывает главу с автоскроллом к стиху
- Шестерёнка ⚙️ в правом верхнем углу — настройки:
  - Перевод (Синодальный / НРП)
  - Размер шрифта (A−/A+)
  - Шрифт (засечки / без засечек / моно)
  - Тёмная / светлая тема
- Все настройки сохраняются между сессиями
- Кнопки «← Пред. глава / След. глава →» внизу текста (работает и между книгами)
- Клавиши ← → на десктопе для переключения глав
- Свайп влево/вправо на мобильных для навигации
- Автозагрузка последнего чтения при открытии без параметров

**Ручной ввод:**
| Формат | Пример | Результат |
|--------|--------|-----------|
| Глава | `Бытие 1` | Глава 1, все стихи |
| Главы | `Бытие 1-3` | Главы 1-3, все стихи |
| Стих | `Бытие 1:5` | Глава 1, стих 5 |
| Стихи | `Бытие 1:5-10` | Глава 1, стихи 5-10 |
| Межглавный | `Бытие 1:28-2:3` | Гл.1 с 28 → Гл.2 до 3 |
| С начала главы | `Бытие 1-2:3` | Гл.1 с 1 → Гл.2 до 3 |
| Несколько книг | `Бытие 1; Матфея 1` | Обе книги |

## Формула GET_BIBLE_PLAN

В ячейке таблицы можно использовать формулу:

```
=GET_BIBLE_PLAN("01-15-2026")
```

Формат даты: `MM-dd-yyyy` (месяц-день-год). Получает план чтения с ODB API.

## Часовой пояс

По умолчанию `GMT+6`. Для изменения отредактируй в `Code.gs`:

```javascript
const todayStr = Utilities.formatDate(new Date(), "GMT+6", "dd-MM-yyyy");
```

## Качество данных

Исходные данные с bolls.life содержали типографические ошибки (отсутствие пробелов после знаков препинания). Исправлено скриптом:

```bash
python3 scripts/fix_formatting.py
```

**Исправлено 10,338 ошибок:**
- `:—` → `: —` (прямая речь в НРП)
- `.А` → `. А` (нет пробела после точки)
- `,и` → `, и` (нет пробела после запятой)
- `;А` → `; А`, `?А` → `? А`, `!А` → `! А`

Запускать после скачивания новых данных.
